# Part 1 submit checklist

Upload these three items together:

1. Word research — `docs/Part1_Research.docx`
   - Fill in student name and student number on the cover.
   - Confirm Arial 12 pt and 1.5 line spacing in Word.
   - Confirm the explanation body is under 500 words.
2. Source code — the Visual Studio solution, not only the `.exe`
   - `MunicipalServicesApp.sln`
   - `MunicipalServicesApp/` project folder
3. Readme — `README.md` at the repository root

Keep a copy. Part 2 and Part 3 extend this same solution.

F5 on Windows (or a Windows VM) before Turnitin. Code that does not compile and run scores 0 for all app marks.
