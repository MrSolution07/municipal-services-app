# Word formatting for Task 1

The brief marks the research only if it is a Word document with:

- Times New Roman or Arial
- 11 or 12 point
- 1.5 line spacing
- A new page for each section

`Part1_Research.docx` is already set to Arial 12 pt and 1.5 spacing, with page breaks before the strategy list, the 500-word explanation, and the reference list.

Before upload:

1. Open the file in Microsoft Word on Windows.
2. File → Options → Proofing is optional; spelling check is enough.
3. Select the explanation section and confirm Word count is 480–500.
4. Replace the name and student-number placeholders.
5. Export or save as `.docx` (do not submit only the markdown).
